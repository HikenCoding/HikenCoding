### 🚀 Projekte

**Projekt "NovaMind 🧠"**
Ein lokaler KI-Agent mit C#/.NET und Ollama in WSL2. Beim Starten der Anwendung auf (CLI) kann er über Texteingaben automatische Abläufe planen und ausführen, um Dateien zu verwalten, PDFs auszulesen und zusammenzufassen. Dazu kann er Quellcode analysieren und Informationen dauerhaft in einer Datei speichern.

**Projekt "Docker Health Monitor 🐳"**
Ein dockerisierter Dienst, der mit Python programmiert wurde. Dieser Dienst überwacht in Echtzeit den Zustand lokaler Docker-Container über den Docker-Socket und verschickt bei Ausfällen oder Neustarts automatische Alarme per HTTP-Webhook.

**Projekt Linux-Monitoring-Stack 🐧**
Ein containisiertes Monitoring-System auf Basis von Prometheus, Grafana und Node Exporter, welches Hardware- und Systemmetriken von Linux-Servern in Echtzeit erfassen. Diese werden auf Grafana-Dashboards angezeigt.

**Projekt "Nginx-Ansible-Secure-Proxy 🛡️"**
Eine Infrastruktur-Lösung, die interne Webdienste über einen Nginx Reverse Proxy mit HTTPS-Verschlüsselung sowie Basic Auth absichert und das Deployment automatisiert über Ansible durchführt.
